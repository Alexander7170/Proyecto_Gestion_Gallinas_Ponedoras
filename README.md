# Gallinas Felices
Es un Software de gestion empresarial enfocado en los requisitos de la empresa Gallinas Felices.

"Gallinas Felices" es una empresa ficticia dedicada al emprendimiento de huevos de gallinas.
Esta empresa quiere mantener organizada sus ventas, producciones y gastos que conlleva el emprendimiento. Quiere poder ver si las ventas aumentaron o no, o si los gastos se estan manteniendo, o si hay un gasto exorbitante, o si las producciones no se estan manteniendo. 
Mi software resuelve esto generando un informe por un rango de fechas, detallando datos de ventas, producciones y gastos que se registro o se concluyo en ese parametro de fechas. Ademas de que cada empleado, previamente registrado por un administrador, va a poder usar el sistema con ciertas limitaciones, podran gestionar los datos importantes para la generacion de un informe.}

#

El objetivo de este proyecto, aparte de tenerlo como base para mi portafolio, es desarrollar mi capacidad para entender un problema real, analizarlo, encontrarle una solucion y desarrollar la solucion.

# Explicación del caso ficticio para Definir alcance.
 La empresa Gallinas Felices es productora de huevos, tiene un galpon de gallinas ponedoras y lo manejan empleados encabezado por un jefe. Esta empresa quiere un software, para los empleados y el jefe, de gestion empresarial. Es decir, registrar los gastos, las ventas y la produccion de huevos con el fin de generar un informe detallado y claro que muestre el ingreso bruto de la empresa.

### Alcance MVP
    
#### Funcionalidades incluidas 

- Se podra generar, ver o eliminar diferentes informes: informes de gastos, informes de ventas, informes de produccion o informe general.

- Se podra realizar operaciones CRUD de ventas, gastos y producciones.

- Se podra registrar el valor del huevo en pesos argentinos

- Se podra realizar filtraciones de ventas, gastos o producciones por fecha o fechas 

- Se podra agregar, eliminar, modificar su permiso de uso del software (actividad) de usuarios

- Los usuarios podran modificar sus propios datos personales. 

#### Funcionalidades no incluidas
- Estimar rendimiento a futuro o predecir informes

- Asignar roles o permisos a usuarios registrados.

- Reflejar el gasto en un informe cuando no se a concluido el pago del gasto.

- Visualizar graficos comparativos de datos e informes.

- Registrar promociones o descuentos contemplados en ventas.

- Registrar rendimiento de empleados de empresa.
